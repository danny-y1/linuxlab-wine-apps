# Windows Application Archive

社区维护的 Windows 应用归档与元数据索引，用于软件保存、兼容性研究和自动化获取。

本仓库不是所收录软件原开发商或发行商的官方仓库。应用名称和商标归各自权利人所有。

## 内容

- `apps/*.json`：归档应用的版本、文件名、大小和 SHA-256
- `schema/*.json`：元数据格式
- Releases：完整应用包的发布位置

完整文件只通过 Releases 提供，不在 Git 仓库目录中拆分保存。归档文件会记录大小和 SHA-256，以便下载后检查完整性。兼容性、许可证和使用条件以对应应用及其运行环境为准。
