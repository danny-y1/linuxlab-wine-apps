# Archive Policy

This repository contains community-maintained application metadata and archived packages for preservation and compatibility research.

- It is not an official repository of the original developers or publishers.
- Package names and trademarks belong to their respective owners.
- Every archived package must include its exact byte size and SHA-256 checksum.
- Files must not be silently replaced under an existing version identifier.
- Complete packages should be distributed through GitHub Releases when possible.
- Segmented files may remain available as a recovery channel until the corresponding Release asset is verified.
- Compatibility and licensing remain properties of the archived application and its intended environment.
